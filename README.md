# Raytrace

My attempt to hack in a raytracer. This is only intended to be a demo.

# Controls

* WASD
* Space/Control
* Left mouse to select objects
* F to switch between edit/movement modes

# Building (Linux)

To build the project on Linux, you need to have CMake, a C++ compiler supporting C++20, and the following dependencies
installed:

* GLFW 3
* OpenGL

Then run:

```bash
mkdir build
cd build
cmake ..
make
```
